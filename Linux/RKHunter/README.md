Auditoría con RKHunter
Objetivo
Verificar la integridad del sistema Linux utilizando RKHunter.

Entorno
Kali Linux
RKHunter 1.4.6
Comandos utilizados
sudo rkhunter --propupd

sudo rkhunter --check

Resultado
Se realizó una auditoría básica del sistema para detectar rootkits y verificar la integridad de archivos críticos.
